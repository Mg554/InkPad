# Roadmap

1. **Library + handwriting canvas** — done
2. **PDF** — import, annotate, export — done
   - Notability-style toolbar, page navigator, nested colored folders — done (needs on-device testing)
3. **Text boxes** — done (needs on-device testing); also images, template
   gallery, export options
4. **Audio recording synced to ink** — record while writing; playback
   replays ink in time with audio; tap a stroke to jump to that moment —
   done (needs on-device testing)
5. **Handwriting search** — on-device recognition with Vision, searchable
   from the library — done (needs on-device testing)
6. **Presentation mode** — NotebookLM-style slide decks made from notes,
   presented full screen (AirPlay mirrors it) with laser pointer, speaker
   notes and narration; PowerPoint, PDF, PNG and Markdown export — done
   (needs on-device testing)
7. **Study with AI** — chat with notes, flashcards with spaced review,
   quizzes, smart notes, with any AI service — done (needs on-device
   testing)
8. **Backup and polish**
   - Back up the whole library to one file (iCloud Drive or Files) and
     restore it, with an automatic copy kept before each restore — done
     (needs on-device testing)
   - Dark-mode chrome, page delete — done
   - Recently Deleted (notes kept 30 days, restore or delete for good)
     and page reorder (drag in the page list, or Move Up/Down) — done
     (needs on-device testing)

9. **Privacy and thinking tools**
   - AI Firewall with three levels (Allowed, This iPad Only, Never),
     Explain This (answers placed on the page), Messy Mode (Organize This)
     and the Memory Heatmap — done (needs on-device testing)
   - Write → Think → Build: turn lasso-selected writing into concepts,
     flashcards, questions and explanations — done (needs on-device
     testing with an AI key)
   - Voice → Timeline: on-device transcripts, chapters and word search
     for recordings — done (needs on-device testing; the simulator has no
     speech models)
   - Restore options (add, choose notes, replace), automatic backups,
     note history, Reminders (Apple Reminders) and Themes with the Theme
     Mixer — done (needs on-device testing)
   - Season themes and glass controls; Expenses, Reminders and Graph
     customization; Refine Handwriting; mind map styles (real tree,
     organic, org chart...), handwritten ideas and Sketch & Reshape —
     done (needs on-device testing, especially Reshape with real
     handwriting and Refine with the pencil)
   - Command Anywhere (⌘K, floating button, three-finger swipe; typed,
     handwritten or spoken commands in English and Arabic) — done (needs
     on-device testing, especially voice and Pencil input)
   - Next ideas, in order: Living Notes; then Focus Mode and Knowledge GPS; later Knowledge
     Versioning, Replay, Spatial Knowledge Graph and Ink → Structure

10. **Agreed next (from the owner's interview, Nov 2026)**
   - **Planner × Flowmodoro**: "Focus on This" on any task starts
     Flowmodoro and logs time on the task; estimate vs actual (learns
     better estimates); auto time-blocking of the day; scheduling by
     energy (hard tasks in the hours the Flowmodoro history shows best
     focus). Views: Today (hour timeline, focus time, reminders),
     Eisenhower matrix, Timeline/Gantt, Weekly Review.
   - **Distraction Box**: catch a stray thought with the Pencil while
     focusing; it goes to a box (also in the sidebar and the drawing
     toolbar), with distraction stats; each item can become an InkPad
     reminder (Apple Reminders).
   - **Focus Garden**: a plant/tree per subject grows with focus time and
     follows the seasons. **Smart breaks**: due flashcards, breathing or
     a walk. **Study-linked tasks**: a task tied to a note or book
     chapter schedules spaced reviews (1, 3, 7 days) when done.
   - **Customize** (brush): timer face (ring, big digits, analog, liquid,
     growing plant) with glow, Planner cards (glass, sticky notes,
     minimal, neon), backgrounds, ambient sounds and break chimes.
   - **Big PDF books** (e.g. How Linux Works 3rd ed., Egan's 13th ed.):
     the book's own outline and colored bookmarks, reading position and
     progress; book and notebook side by side (drag text or a picture
     into notes, linked to the page); split a book by chapters into
     notebooks; fast full-book search (also from ⌘K). Top priority:
     make a mind map or graph from a chosen chapter or text.
   - Done (batch 1, needs iPad testing): PDF Tools hub with merge, split
     (chapters / every N / ranges), pages to a new note, remove, rotate;
     book panel with outline, bookmarks and progress; chapter mind maps
     (on-device or AI) and concept graphs; insert pages from another PDF;
     send pages to a new note.
   - Done (batch 2, needs iPad testing): OCR text layer (Make Searchable,
     English and Arabic, background), full-book search, Text from Area
     with tables and AI clean-up, Make Searchable in PDF Tools.
   - Done (batch 3, needs iPad testing with an AI key): Ask the Book with
     page citations, chapter summary notes, flashcards, exam questions
     and glossary.
   - Done (batch 4, needs iPad testing): Convert (images → PDF, camera
     scan with OCR, web page → PDF, PDF → images, extract images) and
     Protect & Edit (compress, password, unlock, redact, watermark, page
     numbers, sign). Camera scan and signing need the real iPad.
   - Done (batch 5, needs iPad testing): Compare Editions (chapters
     matched by title and text, word-level page diff with colors, AI
     explanation, report note, bookmarks moved to the new edition).
   - Done (batch 6, needs iPad testing): notebook beside the book
     (chapter pages, follow the book, page links, Lasso › Send to
     Notebook as picture or text). The PDF batch is complete.
   - Done (Planner × Flowmodoro batch 1, needs iPad testing): Focus on
     This with time logged on tasks, estimate vs actual with learned
     corrections, Today timeline with Plan My Day (energy-based time
     blocking), Eisenhower Matrix, Weekly Review, Distraction Box (typed or
     handwritten, stats, to Reminders).
   - Done (Planner × Flowmodoro batch 2, needs iPad testing): Focus
     Garden, smart breaks, study-linked tasks with spaced reviews, Gantt
     timeline, Customize (timer faces, card styles, backgrounds, ambient
     sound, chimes).
   - Done (Focus Mode, needs iPad testing): in a note and on its own
     screen, companion (related, quick questions, weak cards), wrap-up
     with a spaced review.
   - Done (Knowledge GPS, needs iPad testing): maps from a book, a tag or
     by hand; islands, metro and skill tree; progress from reading,
     memory, quizzes, focus and marks; next stop, ETA, exam pace, daily
     route to the Planner on approval, reroute. The agreed list from the
     Nov 2026 interview is complete.
   - **PDF tools (PDF24-like, offline)**: organize (merge, split,
     extract, delete, rotate, reorder); "Send pages to a new note" to
     study a few pages deeply; while one PDF is open, pull a page from
     another PDF into it; convert (images ↔ PDF, pages as images,
     extract images, web page → PDF, camera scan); protect (compress,
     password, unlock, redact, watermark, page numbers, sign); compare
     two editions and overlay.
   - **OCR**: a searchable text layer for scanned books (Arabic and
     English, in the background), tables and equations, lasso an area →
     text, export the searchable PDF.
   - **AI with books** (AI Firewall): ask the book with page citations,
     chapter summaries, flashcards and exam-style questions per chapter,
     a glossary linked to Living Notes.
   - **Focus Mode**: clean screen with a small Flowmodoro timer and the

     questions, weak cards); immersive scenes and sounds with the garden;
     a session wrap-up (summary, distractions, spaced review into the

   - **Knowledge GPS**: a map of a book or chapter in selectable styles

     quizzes and focus time, and marked by hand (started, understood,

     chapters, a subject/tag from notes, or a hand-made map (e.g. an exam

     only when approved, with a reroute when behind.

11. **Next-generation plan (owner's review of a product brief, 12 Nov 2026)**
   Rule: each feature also speeds up and hardens the part of the app it
   touches ("both together"), and every change still builds in Swift
   Playgrounds as well as the Xcode-installed app. Batches, in order:
   1. **Library + pages** (done, 12 Nov 2026; dragging pages onto a
      note comes with the split workspace) — favorites, pinning, sorting (name, created,
      edited, custom order); smart collections (recently edited, PDFs,
      notes with audio, unfinished tasks, untitled, by tag); notebook
      covers (colors, gradients) and a grid/list switch; page management
      (multi-select, move pages to another note, duplicate, colored page
      tabs, mixed page sizes).
      Decided (interview, 12 Nov 2026): covers are optional per note
      (first-page preview by default, or a cover with a color, gradient
      or pattern and the title in a chosen font); a Favorites item in the
      sidebar and pinned notes in a row at the top of every list; smart
      collections in a sidebar section, ready-made plus the owner's own
      rules (tag + kind + date); pages move with select › Move to… (note
      and position) and by dragging onto a note; page tabs have a name
      and a color, show on the page edge and in a jump list; page sizes
      are free per page (A4, Letter, square, 16:9, screen, any custom
      size, portrait or landscape); the list view has detailed rows
      (preview, title, folder, tags, pages, audio, edited), sortable by
      column; Custom Order is drag-to-reorder, kept per folder.
   2. **Writing** (done, 12 Nov 2026, needs iPad testing) — pen presets and named color palettes; configurable
      gestures (double tap, two- and three-finger taps); a clean reading
      mode; sticky notes (colors, pinned to pages, turn into Planner tasks
      linked to their page, into pages, grouped) and a sticker studio
      (image packs and saved handwriting, folders, favorites, recents).
      Decided (interview, 12 Nov 2026): presets as a row of chips in the
      toolbar, palettes in the color row's palette button; every gesture
      can be undo/redo, a tool switch, toolbar/Reading Mode or a quick
      command (⌘K, add a sticky, next/previous page); stickies take both
      handwriting and typing; stickers come from built-in packs, saved
      handwriting (lasso), and Photos/Files with on-device background
      removal, organized in folders with favorites and recents.
   3. **Split workspace** — any two notes or PDFs side by side, dragging
      between them.
   4. **AI** — Ask This Page with page and paragraph citations (marking
      outside knowledge); Explain / Translate / math steps from the lasso;
      search by meaning (on-device by default, the connected AI when
      allowed by the AI Firewall); folder and tag suggestions.
   5. **Sync** — a free sync folder in iCloud Drive chosen in Files (no
      CloudKit, which needs the paid program), first between the Swift
      Playgrounds copy and the Xcode-installed copy on the same iPad.
   Postponed: layers and an infinite canvas. Real-time collaboration is
   out of scope (needs a paid server or program).
