# Roadmap

1. **Library + handwriting canvas** — done
2. **PDF** — import, annotate, export — done
   - Notability-style toolbar, page navigator, nested colored folders — done (needs on-device testing)
3. **Text boxes** — done (needs on-device testing); also images, template
   gallery, export options
4. **Audio recording synced to ink** — record while writing; playback
   replays ink in time with audio; tap a stroke to jump to that moment —
   done (needs on-device testing)
5. **Handwriting search** — on-device recognition with Vision, indexed per
   page, searchable from the library
6. **Presentation mode** — NotebookLM-style slide decks made from notes,
   presented full screen (AirPlay mirrors it) with laser pointer, speaker
   notes and narration — done (needs on-device testing)
7. **Backup and polish** — export/import a whole library to iCloud Drive,
   page delete/reorder, recently deleted, dark-mode chrome

Not yet possible with PencilKit: dashed and dotted pen strokes.

AI stays on the iPad: slide decks use Apple Intelligence's on-device model
when it is available (iPadOS 26 and later), with an offline outliner
otherwise. Other AI features (chat with notes, flashcards) could use the
same on-device model later; nothing that needs a cloud service is planned.
