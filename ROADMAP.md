# Roadmap

1. **Library + handwriting canvas** — done
2. **PDF** — import, annotate, export — done
   - Notability-style toolbar, page navigator, nested colored folders — done (needs on-device testing)
3. **Text boxes** — done (needs on-device testing); also images, template
   gallery, export options
4. **Audio recording synced to ink** — record while writing; playback
   replays ink in time with audio; tap a stroke to jump to that moment —
   done (needs on-device testing)
5. **Handwriting search** — on-device recognition with Vision, searchable
   from the library — done (needs on-device testing)
6. **Presentation mode** — NotebookLM-style slide decks made from notes,
   presented full screen (AirPlay mirrors it) with laser pointer, speaker
   notes and narration; PowerPoint, PDF, PNG and Markdown export — done
   (needs on-device testing)
7. **Study with AI** — chat with notes, flashcards with spaced review,
   quizzes, smart notes, with any AI service — done (needs on-device
   testing)
8. **Backup and polish**
   - Back up the whole library to one file (iCloud Drive or Files) and
     restore it, with an automatic copy kept before each restore — done
     (needs on-device testing)
   - Dark-mode chrome, page delete — done
   - Page reorder, recently deleted — next

Not yet possible with PencilKit: dashed and dotted pen strokes.

AI is optional and your choice: study features and slide writing use the
service you connect with your own key (Claude, ChatGPT, Gemini, OpenRouter,
Groq, DeepSeek, Mistral or any OpenAI-compatible service), or Apple
Intelligence on the iPad. Without one, slides are outlined offline.
